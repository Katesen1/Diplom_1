Были созданы юнит тесты, покрывающие класс Burger test_burger.py:
1. test_burger_init - Создание бургера
2. test_set_buns - Установка булочек в бургер
3. test_add_ingredients - Добавление ингредиентов в бургер
4. test_remove_ingredient - Удаление ингредиентов из бургера
5. test_remove_ingredient_error - Возникновение ошибки при удалении ингредиентов из бургера с 0 индексом и индексом больше, чем количество ингредиентов
6. test_move_ingredients - Перемещение ингредиентов в бургере
7. test_move_zero_ingredients - Возникновение ошибки при перемещении пустого списка ингредиентов
8. test_move_more_than_ingredients - Возникновение ошибки при перемещении ингредиетов с индексом больше,чем количество ингредиентов
9. test_get_price - Получение стоимости бургера
10. test_get_receipt - Получение рецепта бургера
